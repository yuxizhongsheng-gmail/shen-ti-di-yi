## 全书觉醒线（为什么是这个顺序）

他不是按"修炼顺序"（身体→注意力→语言）排，而是按**觉醒顺序**排：
**先拆掉脑子里的两层幻觉（声音 ch1 / 叙事 ch2）→ 看清你被什么悄悄塑造（ch3）→ 夺回最稀缺的资源（注意力 ch4）→ 学会用工具（语言 ch5 / 结构 ch6）→ 回到肉身这个底座（身体 ch7）→ 转化为行动（做事 ch8）→ 影响世界（表达 ch9）。**
身体放第 7 章，正因为：得先把雾清了，肉身这块压舱石才接得住。

## 第一章 你脑子里那个声音不是你（p10）　★样章已写
- **主旨**：脑子里那个评判你的声音，不是你，只是你最早发明的工具——语言。砸碎这把锁，全书才进得了门。
- **论点链**：工具/电脑gpt类比 → 把工具当成"我"是一切痛苦之源 → 语言我对外界毫无杀伤力、却对你完全暴政 → 庄子《逍遥游》「举世誉之而不加劝，举世非之而不加沮」→ 排序：身体>注意力>语言>别人的语言 → 主奴反转。
- **锚点**：禁言1·**01-22 整夜**（全章主矿脉）。
- **现状**：`drafts/01-…` 已写，主编自评"优秀偏上"，可作全书声音基准。

## 第二章 叙事是这个时代最大的精神鸦片（p42）
- **主旨**：第二层幻觉——叙事。给自己/世界编故事，是这个时代最廉价、最上瘾的精神鸦片。
- **论点链**：宏大叙事让人在意义里内耗 → 连给自己编故事（我是失败者/一把好牌打烂）都要警惕 → 明星八卦、远在天边的事，都是"你的"宏大叙事 → 你一叙事，就意味着你不干活了、开始内耗了 → 出路：少叙事。
- **并入**：内耗的病理学（自我对话→反刍→抑郁螺旋，禁言2·02-27）很可能落在本章或第六章。
- **锚点**：禁言1·02-01「多建立结构，少一些叙事」「远离你的、无关于你的叙事，都是宏大叙事」；禁言2·02-27 抑郁成因链。

## 第三章 那些悄悄塑造你的力量（p74）
- **主旨**：你以为是"你自己"的好恶、审美、意义系统，多半是别人在你无意识时悄悄注入的。
- **论点链**：过度社会化杀死审美与诚实（言不由衷反塑造不诚实的内心）→ 你的意义系统是别人注入的，不是你选的 → 信息环境悄悄塑造你（朋友圈信息质量≈0还耗情绪）→ 你嵌入的价值网络、身边的关系，都在给你定义 → 把这些力量"如实"看见，才能重选。
- **并入**：审美/诚实/智能美善、降噪（关朋友圈、远离烂人）、价值网络对人的塑造。
- **锚点**：禁言1·12-24「审美能力的丢失，往往跟过度的社会化有关」；01-22「重建你们的意义系统」；禁言2·02-26 降噪。

## 第四章 注意力是你唯一真正的货币（p101）
- **主旨**：注意力是你唯一真正稀缺、且可自由支配的货币——也是自由的边界。
- **论点链**：控制不了注意力就谈不上自由 → 你不控制它，它就被别人使用/滥用 → 别给观众、恋人、想象中的目光当狗 → 关系的本质=你愿意把注意力浪费在谁身上 → 浪费别人的注意力，是被世界爱的证据。
- **并入**：关系脊椎（注意力给谁=关系）、反馈奴役（给观众当狗）。
- **锚点**：禁言1·02-01「控制不了自己注意力的人，是谈不上自由的」「你做 ip，有反馈，你马上就给观众当狗」；禁言2·02-27「浪费别人的注意力，就是我们被世界爱的证据」。

## 第五章 语言是你最重要的技术（p122）
- **主旨**：第一章拆掉"语言我"的暴政；这一章反过来——语言是人类最早、最强的技术，学会用它影响世界。
- **论点链**：语言是人类最先发明的工具/技术，低成本却威力巨大 → 马斯克、特朗普怎么用语言改造世界、把世界当游乐场 → 有人用语言把世界变审判席，有人变游乐场 → 干净你的语言，让好的语言高频提醒你 → 但要"细水长流"，别被自己的语言轻易刺激。
- **锚点**：禁言1·01-22「语言是我们人类最重要、最核心，也是最先发明的工具」「世界是你的游乐场」；禁言2·02-27 马斯克"第一性原理/我要我觉得"。

## 第六章 结构化这个世界（p154）
- **主旨**：与叙事相反的认知方式——把经历提炼成结构，而不是反复咀嚼故事。
- **论点链**：一件事想十次，不如复利一下、想一次想清楚 → 提炼结构（什么对，多做；什么错，少做）→ 遇人不淑也提炼结构，未来躲开 → 不断提高你对世界的预测准确度 → 这才是"反思"，叙事不是。
- **并入**：复利的认知面（想清楚一次顶十次）。
- **锚点**：禁言1·02-01「结构化这个世界……不停增加你预测的准确度」「想某件事想十次，能不能复利一下，想一次就想清楚」。

## 第七章 你的身体是你的核心生产力（p176）
- **主旨**：清完脑子的雾，回到最确定的底座——身体。它不是消耗品，是你的核心生产力。
- **论点链**：身体是第一工具/载具，注意力身体都只是"你"的容器 → 情绪多半只是生化反应（前额叶缺糖→杏仁核夺权），不关乎你这个人 → 睡眠、低碳、补剂、节律的机制 → 痛苦几天、习惯十天、爽八十年，活到 110-120 → 身体杠杆是第一杠杆。
- **并入**：身体第一脊椎、生化论据、"爽八十年"。
- **锚点**：禁言1·01-22 工具排序；禁言2·02-26 血糖/血清素/抑郁机制、「爽八十年」「首先的杠杆，是你的身体杠杆」。

## 第八章 做事的逻辑（p200）
- **主旨**：把认知落成行动的次序学。
- **论点链**：先想清楚"要不要做"（结果对你重不重要、愿付多少注意力），别在"怎么做"时回头想"能不能" → 第一次走出来是勇气，第一百次还犹豫是莽夫 → 做了、坏了、好了、总结、调整、再做 → 确定性越高，成长性越低 → 复利的核心是不停下；运气是概率，大力出奇迹。
- **并入**：概率脊椎、复利的行动面、反馈/迭代。
- **锚点**：禁言1·02-05「不要在怎么做的时候去想能不能」「第一次是勇气，第一百次还这样就是莽夫」；「复利的核心不是每次都很好，而是不停下」。

## 第九章 表达是你影响世界的唯一接口（p225）
- **主旨**：所有内功的出口——表达。不表达，世界就接不到你，你也无法被定价。
- **论点链**：必须公开发出来，语言才和世界接上轨 → 成长≠赚钱，你嵌入什么价值网络决定你值多少 → 定向服务才有溢价，公开你的成长别人才有机会给你钱 → 作品大于学历；三种杠杆（卖自己/一份时间多次售卖/金融）→ 稀缺与击穿=定价权 → AI 是最大平权，核心是提问，为人生融资。
- **并入**：脊椎四全部（定价/价值网络/杠杆/稀缺）、AI 红利、作品/被看见。
- **锚点**：禁言2·02-25 价值网络/定向服务/出租车例子；02-27「必须让语言和世界接上轨」；`cards/04` 全部；⚠️那条 AI"定价公式"只作附注。
