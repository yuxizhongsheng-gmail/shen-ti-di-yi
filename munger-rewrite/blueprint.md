# 《别被自己的脑子骗了》改写蓝图

> 后续所有逐章、逐段改写的统一标准。本文件不含正文。

## 1. 新书定位（一句话）

《别被自己的脑子骗了》是一本给普通人的**“反自欺操作手册”**：沿用《如实所现》的内核——把被放大的东西还原到真实尺寸——换上查理·芒格式的判断方式，教你识破脑子里那个不收费、不打烊、专门夸大的播报员，把每天的痛苦、焦虑和拖延，当成一道道可以拆开检查的认知误判来处理。锋利但不冷血，讲机制不讲口号，面向普通生活不面向股票。

## 2. 核心命题

- 原书命题：把被放大的东西，还原到真实尺寸。
- 芒格式转换：你最大的麻烦不是世界太难，是你太轻易相信脑子里第一个冒出来的结论——而它通常是被情绪、叙事、旧习惯放大过的次品。
- **最终推荐命题**：**别急着相信你的第一反应。先问一句：这是事情本身的尺寸，还是我脑子替它加上去的？**
- 为何统摄全书：九章是同一动作的不同战场——看清(识别谁在放大)→拆解(拆掉放大的工具)→重建(还原后把力气投到真实的事)。这一句正是贯穿“识别→拆解→还原→行动”的总开关，既芒格(反第一反应、反自欺)又原书(真实尺寸)。

## 3. 内核与外壳的关系

- **必须保留(内核)**：总命题“真实尺寸”及收尾提问；九章结构与因果链；核心比喻(昏君/小我、硬件/软件、照妖镜、摆渡的船、内在记分牌)；作者“非鸡汤/非积极心理学口号”的自我声明；面向普通人的生活场景。
- **可以重写(外壳)**：语气、锋利度、铺陈密度；安慰句→判断句；抽象机制→芒格式因果/激励/系统语言；删文学化形容词。
- **必须保温(5处保温区)**：第三章自我暴力段、第七章身体全章、第九章“摆渡的船/站我肩膀上看更远”、后记温柔收束、第一章“闭眼坐三十秒”体验段。
- **可以更冷更硬**：第二章五种叙事(冷峻清单)、第四章“谁偷你注意力”(激励+你输是必然)、第六章五步拆解(工程师短句)、第八章“想清楚再做”(逆向打脸=拖延)。
- **不能强行芒格化**：保温区。规则——保温区只借芒格的“诚实”，不借他的“刻薄”。

## 5. 语言宪法

1. 句子长度：短句为骨，长短交错；每段至少一句重锤；连三长句必断。
2. 段落节奏：诊断→机制→工具；保温区可慢可铺陈，非保温区不许拖。
3. 判断句比例：非保温章节每节≥2–3句硬判断；保温段≤0–1句且须温和。
4. 何时锋利：讲“人对自己的纵容”(自欺/拖延/被偷的注意力/硬扛)时，锋利对行为/机制，不对人格。
5. 何时保温：保温区五处，只用芒格的诚实，不用刻薄。
6. 像芒格：“不是A是B”“你以为X其实Y”；用激励/机会成本/反向解释；先夺借口再给冷真相；承认自己也会犯错(谦逊)。
7. 假芒格：堆名言、塞投资术语、为冷而冷、金句无判断。
8. 像AI：首先/其次/此外/总而言之的工整四段、“在当今社会”“值得注意的是”、排比堆砌、点到为止不下判断。删。
9. 像鸡汤：你值得更好的/相信自己一定可以/一切都会好起来/你本来很优秀。禁。
10. 破坏气质：慢章提速、场景换大词、关怀改嘲讽、提醒写成审判。
11. **用词 register（铁律）**：平实而有教养，精确、克制、略带书卷气与干涩。芒格的“硬”来自**判断的精确**与**不留情面的诚实**，绝不来自网络口语、痞腔、油腻或粗鄙。
    - 禁用市井/网络口语腔：“人有个毛病”“往大了想”“加了料”“我不跟你打折扣”“撞见”“接地气”式俏皮。
    - 倾向用词：根深蒂固的倾向 / 高估 / 审慎 / 愚行 / 现成说辞 / 不打算含糊 / 逐一辨认 / 逐层卸去。
    - 通俗 ≠ 粗俗：可以让普通人读懂，但不能靠降格到俚俗去“显得直接”。
    - 自检：这句话像不像《穷查理宝典》里译出来的句子？像市井段子，就重写。

## 7. 后续执行流程（一次一章）

1. **建图**：你说“开始第N章”。我读原书该章，产出《第N章·改写地图》(沿用前言七项格式)，落盘 source-and-notes.md，提交。只建图不改写。
2. **你确认/纠偏**：地图定稿才进下一步。
3. **逐段改写**：你发几百字–1000字。每段：source-and-notes.md 留底+一句判断；manuscript.md 写改写稿；提交推送。一段一提交，便于单独回退。
4. **整章统一**：全章改完后通读，统一口径/关键词/节奏/保温区/删重复，提交“第N章·整章统一”版。
5. **下一章**：回到第1步。

九章走完后做跨章统一(命题一致性、术语表、语气配比)+前言/后记呼应收尾。
