# 《别被自己的脑子骗了》

> 《如实所现》的查理·芒格版改写。

这本书的核心不是安慰读者，而是提醒读者一件事：

**别太相信脑子里的第一反应、情绪里的解释、叙事里的幻觉，以及环境给出的短期奖励。**

人最大的麻烦，往往不是世界太复杂，而是自己太容易相信一个临时的、被情绪和旧习惯生成的结论。

## 工作方式

- 原文《如实所现》约 2.5 万字，**逐段**改写，一次只处理一小段。
- 每段先理解、再判断、再改写，不一口气处理整本书，不擅自跳章。
- 改写成查理·芒格式的**认知判断**，不是心理疗愈、不是成功学、不是投资书、不是巴菲特案例集。

## 用到的思维工具

逆向思维 · 避免愚蠢而非追求聪明 · 激励机制决定行为 · 机会成本 · 复利 ·
多元思维模型 · 心理误判清单 · 常识判断 · 长期主义 · 反自欺 · 反第一反应 ·
反情绪化解释 · 冷静、短促、直接地指出问题。
